# Mission: Advanced System Design & Software Architecture

## Why
Transition from a passive consumer and prompt-committer of AI-generated code into an authoritative technical architect who rigorously evaluates trade-offs, anticipates failure modes, chooses appropriate distributed patterns, and dictates sound architectures for freelance client systems and personal projects.

## Success looks like
- Autonomously evaluate any system architecture or AI-proposed design across latency, throughput, consistency, fault tolerance, and operational cost.
- Produce comprehensive High-Level Design (HLD) specifications (data flows, partitioning schemes, caching hierarchies, event models) for real-world web scale systems.
- Identify specific flaws and edge cases in AI-generated architectures (e.g., dual-write inconsistencies, cache stampedes, unindexed fan-outs) and prescribe concrete fixes.
- Bridge high-level distributed systems down to low-level modular software design patterns in TypeScript/Node with clean domain seams.

## Constraints
- Time commitment: ~30 minutes daily.
- Primary programming environment: TypeScript / Node.js.
- Prioritize high-level distributed system architecture first before drilling into class-level software design patterns.

## Out of scope
- Theoretical/compiler design and low-level C/C++ memory management.
- Pure DevOps/Kubernetes cluster administration (focus remains on architecture and system design patterns, not cloud infra plumbing).
- Low-level design patterns (GoF patterns, micro-abstractions) until high-level system foundations are locked down.
